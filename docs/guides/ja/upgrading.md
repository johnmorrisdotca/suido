## バージョン 1 内の更新

現在の公開メジャーは 1 です。各更新は[変更履歴](../../../CHANGELOG.md)で確認してください。このドキュメントの更新は案内、例、画面の Docs リンクを追加し、公開 SDK と同梱問題の値は変えません。

埋め込みの共通仕様では `grid`、表示サイズ、日替わり、テーマ、幅、ラベルが加わりました。従来の `size="7x7"` は引き続き問題寸法を選びます。新しい例では `grid="7x7"` と `size="medium"` を分けます。独自コードは日替わりより優先し、`options` のコールバックだけの変更では盤面を再開しません。古いマークアップの移行は[埋め込みの仕様](../../embeds.md)で確認してください。

## 保存した盤面を保つ

元のコードと進捗を組で保管します。現在の向きを表すコードだけでは手数を保存できません。公開済みの従来問題は同一性を保ち、大きなピースの問題集は別に選びます。生成問題を正確に再現する必要があるなら、返された種、設定、バージョンも保存します。

別のパイプゲームから移行する際は、完成条件を `network`、`drains`、`inlet-outlet` のどれに対応させるか決めます。文字を推測して他形式のコードを変換せず、標準の盤面を作って検証し、コードにします。ネットワークの環や余りの管、一括回転には独自の規則があります。[規則の説明](rules.md)から確認してください。
